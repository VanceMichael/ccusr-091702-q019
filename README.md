# 水域赛事安全指挥核

本服务用于公开水域计时、安全冻结、救援和成绩封存。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：赛事版本、选手、计时设备、检查点事件、救援资源、赛段、异常案、成绩版本。

计时事件不能越过人工安全状态；赛段冻结联动救援覆盖；改道需要职责分离；成绩更正发布新版本。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/water_race_command.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
